# Проверки и ограничения

Публичная поставка: Windows 0.1.7 и Android 0.1.6. Это тестовая версия.

| Проверка | Результат |
| --- | --- |
| Полный набор Go-тестов с сетевыми build tags | Пройден |
| Импорт VLESS/REALITY, повреждённые подписки и сохранение профилей после HTTP 502 | Пройден |
| Выбор маршрута, резерв WARP, более быстрый DPI, UDP, три ошибки и пауза переключений | Пройден |
| Установщик Windows, безопасная распаковка и обновление неизменившихся файлов | Пройден |
| Установка Windows 0.1.7 поверх предыдущей версии, служба и IPC | Проверены |
| Автозапуск и настройка автоподключения, сохранение выключенного значения | Автоматические проверки пройдены |
| Реальный повторный вход в Windows с автоподключением | Требует проверки |
| Анализ Dart и 15 widget-тестов с PT Sans | Пройдены |
| Windows Flutter engine smoke-test | Код завершения 0 |
| Комплект Windows внутри EXE и контрольные суммы всех 186 файлов | Проверены |

| Видео, реальные звонки, смена сети, сон и аварийное восстановление на обеих платформах | Требуется матрица docs/acceptance.md |

HTTP/TLS/STUN не подтверждают воспроизведение видео и голосовые звонки.
Автонастройка WARP использует неофициальный механизм wgcf. Успешная регистрация
не означает доступного туннеля: приложение проверяет транспорт и выход WARP.
Непроверенный WARP не выбирается как рабочий резерв.

XHTTP не реализован в этой версии. Неподдерживаемые параметры показываются
при импорте. Подписки, личные ключи, настройки устройств, необработанные
crash-журналы и ключ подписи APK в публичный репозиторий не входят.

APK подписан личным сертификатом проекта; для обновлений сохраняется тот же
сертификат. Резервная копия ключа остаётся у владельца. Windows EXE не имеет
Authenticode-подписи.

Закреплённые версии и SHA-256 компонентов находятся в components.lock.json.
Матрица испытаний перед повседневным использованием: docs/acceptance.md.

Публичный APK 0.1.6 содержит пересобранную из соответствующего снимка исходников
Go-библиотеку с относительными module replacements: локальные пути сборки
удалены из build info. API, Kotlin/Flutter и настройки не менялись; остальные
ZIP-записи APK совпадают. APK заново подписан тем же личным сертификатом.
