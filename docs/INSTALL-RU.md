# Установка Маршрут на Windows

Для другого компьютера нужен только файл
`Marshrut-0.1.7-Windows-x64-Setup.exe` и свой VLESS-ключ или ссылка подписки.
Поддерживаются Windows 10/11 x64.

1. Запустите установщик и подтвердите права администратора Windows.
2. Откройте «Маршрут» из меню «Пуск».
3. В «Серверах» вставьте ключ `vless://` или ссылку подписки и импортируйте её.
4. Нажмите «Подключить» и дождитесь проверки маршрутов.

Установщик содержит интерфейс, ядро, сетевые компоненты и шрифт. Отдельные
папки runtime/windows-x64, исходники, Go, Flutter и приложение Cloudflare WARP
не нужны. Личные подписки и ключи в установщик не входят.

В «Настройках» есть два отдельных тумблера:

- «Автозапуск» — открывать приложение при входе в Windows.
- «Подключаться при автозапуске» — после такого запуска включать соединение.

Оба включены по умолчанию. Автоподключению нужен добавленный профиль.
При обычном ручном открытии окна подключение остаётся ручным.
Если вы отключили VPN кнопкой, приложение не включает его снова от обновления
статуса; автоподключение сработает при следующем запуске вместе с Windows.

Для обновления закройте окно «Маршрут» и установите новую версию поверх старой.
Сохранённые подписки и настройки остаются на компьютере.
