# Каталог маршрутов Маршрута 0.1.11

Во вкладке «Правила» находится локальный каталог приложений, сайтов, сервисов
и IP-подсетей. В нём есть 31 встроенная запись, автоматически обнаруженные
программы и ваши адреса. Поиск работает по названию, домену, IP и пути EXE;
фильтры — по типу и источнику. Одна запись может относиться к нескольким типам.

## Быстрая настройка

Нажмите кнопку маршрута в карточке записи. Можно выбрать прямое соединение,
автоматический VPN, конкретный сервер, WARP, DPI для TCP или блокировку.
В списке серверов работает поиск. «По общим правилам» убирает только отдельное
исключение этой записи, сохраняя её в каталоге. Новое исключение для приложения
использует полный путь EXE и добавляется выше общих правил.

«Добавить сайт или IP» принимает обычную ссылку http/https, домен, IPv4/IPv6
или подсеть CIDR. Путь страницы и порт из ссылки не участвуют в маршрутизации:
правило относится ко всему домену и его поддоменам. Название можно оставить
пустым; оно заполнится адресом. Повтор одного и того же простого адреса
отклоняется. По умолчанию новая запись не создаёт отдельного маршрута.

В меню ⋮ можно изменить название, простой адрес пользовательской записи или
удалить запись вместе с её правилом. Полные условия и приоритеты редактируются
через «Редактор правил». Для обнаруженного приложения вместо удаления выберите
«По общим правилам»: запущенные процессы продолжают обнаруживаться автоматически.

В меню «Перенос каталога» можно скопировать весь каталог и правила в JSON.
Записи без индивидуального маршрута тоже попадают в файл. Импорт заменяет
сохранённые записи и правила одной операцией. JSON может содержать пути к EXE,
если для них сохранены условия.

Если DNS-запрос обслуживает общий процесс Windows, для него применяются правила
по известному домену и владельцу сокета. Когда для TCP и UDP совпадают разные
правила, DNS предпочитает явно выбранный доступный туннель. Блокировка одного
протокола оставляет возможность разрешить имя для второго.

«Почему этот маршрут?» показывает первое совпавшее правило и число совпадений
ниже него отдельно для TCP и UDP. При активном соединении видны сохранённая
и применённая версии. Для приложения можно ввести сайт или IP и проверить
их вместе. Это предпросмотр условий без сетевых запросов; он не измеряет
трафик и не учитывает неизвестные IP сайта, DNS-брокер и порт соединения.

## Обнаружение и хранение

Программы текущего пользователя Windows обновляются каждые 10 секунд, кнопка
«Обновить приложения» запускает проверку сразу. Процессы одного EXE объединяются,
закрытые программы запоминаются. Во вкладке приложений доступен фильтр запущенных.
Само обнаружение не создаёт правил и не меняет их ревизию. Защищённые процессы
без доступного пути, процессы других учётных записей и сам Маршрут исключены.

Локальная SQLite лежит рядом с защищённым файлом настроек, с суффиксом
`.routing.sqlite`. Правила, каталог и метаданные приложений хранятся одним
зашифрованным снимком DPAPI, обновляемым транзакцией. Миграция старых настроек
выполняется один раз. База имеет приоритет над совместимой копией в старом
файле. VPN-ключи и подписки остаются в прежнем DPAPI-хранилище.
Содержимое базы нельзя переносить между учётными записями обычным копированием.

Названия и пути приложений не попадают в диагностический отчёт. Командные
строки, содержимое окон и память процессов не читаются. JSON-экспорт в общем
редакторе содержит действующие/отключённые правила, включая их условия и пути,
но не весь каталог неактивных записей и не VPN-ключи.

Сохранение не прерывает соединение. Маршруты применяются при следующем
подключении или кнопкой «Применить», которая переподключает VPN. Простое
переименование не требует применения. Если новые правила не запускаются,
приложение пытается запустить предыдущий снимок; сохранённые правки остаются
для исправления. Явное отключение пользователем отменяет восстановление.

## Как редактировать

Откройте «Правила» → «Редактор правил». Нажмите на название правила или откройте меню ⋮ → «Редактировать». Можно менять название, категорию, маршрут, TCP/UDP, домены, процессы, пути к EXE и IP/подсети. Сопоставление процессов и путей не зависит от регистра букв.

В меню ⋮ также доступны дублирование, удаление и перемещение выше/ниже по приоритету. Новое правило добавляется в начало списка. Для временного отключения используйте переключатель.

«Копировать JSON» сохраняет список в буфер обмена, «Импорт JSON» заменяет список импортированным. «Стартовый список» восстанавливает все 31 правило после подтверждения. Поля условий проверяются перед сохранением, параллельное изменение списка не перезаписывается молча.

Если VPN включён, сохранение не прерывает текущую связь. Появится кнопка «Применить»: она переподключит VPN с новым списком. При выключенном соединении правила применятся при следующем подключении. Изменения также сохраняются после перезапуска.

## Значение маршрутов

- **Напрямую** — через вашего провайдера. Для игр это выбранный вами стартовый режим; VPN переключается вручную в карточке конкретной игры.
- **Автовыбор** — существующая проверка доступности для выбранного профиля (YouTube, Discord, Telegram, AI или остальной интернет). Действует настройка прямого резерва.
- **VPN автоматически** — рабочий VLESS, затем проверенный WARP. Прямого резерва нет. Для AI-предустановок учитываются проверки доступности AI-сервиса.
- **Конкретный сервер / WARP** — явно выбранный путь. Если его нет в текущем комплекте настроек, трафик по правилу блокируется.
- **DPI / TCP** — только TCP, обработка HTTP/TLS на портах 80/443. Через этот маршрут игровой UDP не идёт.
- **Блокировать** — запрет совпавших TCP/UDP-соединений.

Правило qBittorrent/Transmission изначально выключено: переход торрент-клиента на прямое соединение требует явного включения правила.

## Проверки и границы

Проверены транзакции и откат SQLite, шифрование, однократная миграция, защита от потерянных правок, сохранение пустого списка и отказ от сброса повреждённой/будущей схемы. Локальные тестовые HTTP-прокси с настоящим Windows-ядром подтверждают выбор маршрута по домену, IP-подсети и полному пути EXE, порядок правил, отключение и блокировку отсутствующего пути. Системные маршруты в этих тестах не меняются.

Пройдены тесты ядра, включая нормализацию, приоритеты, сохранение порядка и пустого списка, обработку отсутствующего маршрута и работу VPN без прямого резерва. Пройдены анализ Flutter и 30 widget-тестов, включая редактор на ширине 360 и 1200 пикселей.

Это стартовый набор, не полный перечень всех CDN и вспомогательных процессов. Проверка реальных сессий Dota 2, CS2 и PUBG на этом ПК не выполнялась. Путь игрового процесса определяет Windows; при нестандартной сборке/лаунчере условия можно поправить в редакторе.

Список основан на выбранной вами политике и общедоступных именах сервисов. Источники для технических условий: [правила sing-box](https://sing-box.sagernet.org/configuration/route/rule/), [домены и сетевые требования Steam](https://help.steampowered.com/en/faqs/view/2EA8-4D75-DA21-31EB), [справка PUBG о TslGame.exe](https://support.pubg.com/hc/en-us/articles/115004167294-How-to-resolve-TslGame-exe-error), [домены Epic](https://www.epicgames.com/help/c-36624475/c-35761596/which-domains-need-to-be-whitelisted-to-reach-the-epic-servers-a15422130?lang=en-US). Общие CDN целиком, например akamaihd.net, в прямой список не добавлены.
