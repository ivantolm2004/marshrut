# Приёмка на личных устройствах

Заполняется по фактически выполненным испытаниям. Неотмеченные пункты не считаются пройденными.

## Windows

- [ ] Установщик создаёт службу и пользователь открывает интерфейс без повышения прав.
- [ ] Именованный канал доступен владельцу и SYSTEM; другому пользователю отказано.
- [ ] TUN перехватывает IPv4/IPv6, локальная сеть доступна, DNS следует выбранным правилам.
- [ ] DPI-фильтр исключает все реальные адреса VLESS/WARP, включая обновившиеся DNS-ответы.
- [ ] При отказе драйвера zapret показывает ошибку, VLESS/WARP остаются управляемыми.
- [ ] Обычное отключение, остановка службы, принудительное завершение и перезагрузка восстанавливают доступ в Интернет.
- [ ] Повторная установка и удаление приложения корректно останавливают службу.
- [ ] После установки интерфейс запускается при входе владельца; выключатель автозапуска сохраняется после обновления.

## Android без root

- [ ] Подписанный APK устанавливается на Android 10+ arm64 и обновляется тем же ключом.
- [ ] Разрешение VPN принимается/отклоняется корректно; приложение не включает второй VPN.
- [ ] Все внешние сокеты libbox и tpws защищены, отсутствует повторный захват в VPN.
- [ ] При отказе SCM_RIGHTS/protect tpws закрывает соединение, не создаёт цикл.
- [ ] Wi-Fi ↔ мобильная сеть, потеря сети, сон и отзыв VPN-разрешения обработаны.
- [ ] Отключение удаляет TUN; уведомление соответствует состоянию службы.
- [ ] В каталогах приложения отсутствует открытый снимок конфигурации libbox.
- [ ] После перезагрузки восстанавливается только ранее подключённый VPN с выданным разрешением; ручное отключение и выключатель автозапуска соблюдаются.
- [ ] При недоступной сети после загрузки выполняются ограниченные повторные попытки без зависшего TUN.
- [ ] На Samsung S25 FE версия 0.1.4 подключается после появления ключика VPN и не завершается при смене физической сети.
- [ ] После аварийного завершения «Диагностика» показывает предыдущий этап/системный код, копируемый отчёт не содержит сообщений исключений, ключей и сырых crash-данных.
- [ ] В 0.1.5 проверены фактическая версия APK, время и функции нативного сбоя; Java reason=4 не приравнивается к native reason=5 по устаревшему crash-файлу.
- [ ] В 0.1.6 после первого пакета TUN отсутствует nil pointer в FindConnectionOwner; при неизвестном UID продолжается маршрутизация по сервисам.

## Реальные сервисы и отказоустойчивость

- [ ] YouTube: воспроизведение не менее 10 минут и перемотка.
- [ ] Discord: текст и двусторонний голосовой звонок не менее 5 минут.
- [ ] Telegram: сообщения, медиа и двусторонний звонок.
- [ ] Браузер: обычные, заблокированные и локальные сайты.
- [ ] AI-сервисы: вход в аккаунт и выполнение запроса через подходящую страну VLESS.
- [ ] WARP: handshake подтверждён реальным двусторонним туннельным трафиком и trace `warp=on/plus`.
- [ ] WARP регистрируется без кнопки; после ошибки напрямую повторяет регистрацию через рабочий VLESS, не прерывая текущие соединения.
- [ ] WARP используется только при недоступном VLESS; после восстановления VLESS возвращается с соблюдением паузы.
- [ ] Для YouTube/Discord/Telegram TCP выбирается рабочий zapret с меньшей задержкой, чем у VLESS; Android tpws не получает UDP.
- [ ] После трёх неудачных проверок выбирается доступный резерв; соблюдается пауза 60 секунд.
- [ ] При смене пути пользовательские запросы не переотправляются автоматически.
- [ ] При HTTP 502/повреждённой подписке сохраняются последние рабочие настройки.
- [ ] IPv6 и DNS проверены захватом пакетов на обоих типах подключения.

HTTP/TLS/STUN-пробы не засчитываются как проверка воспроизведения и звонков.
